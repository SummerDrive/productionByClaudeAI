# テキスト・ドラムシーケンサー

英語の文章を先頭から1文字ずつ解釈し、16ビートのドラムパターンとして再生するブラウザアプリです。インターネット接続不要、単一のHTMLファイルのみで動作します。

## 使い方

1. `text_drum_sequencer.html` をダブルクリックしてブラウザで開く
2. 「変換する文章」欄に好きな英文を入力する
3. 「再生」ボタンを押すと、文章が音のパターンとして再生される

## 文字割り当て

以下の5つの音要素に、好きな文字を割り当てられます。

| 音要素 | 初期値 |
|---|---|
| ハイハット(クローズ) | `h` |
| ハイハット(オープン) | `o` |
| スネア | `s` |
| ハンドクラップ | `c` |
| バスドラム | `b` |

- 各入力欄には複数の文字を割り当て可能です。例えばバスドラムの欄に `bd` と入力すると、文章中の `b` と `d` の両方でバスドラムが鳴ります。
- 割り当てた文字以外(または未割り当ての音)の文字は休符として扱われます。
- 文字は大文字・小文字を区別せず判定されます。

## スペース・記号の除外

「スペース・記号等を除外して英字のみで変換する」にチェックを入れると、文章からスペース・句読点・数字などを取り除き、英字だけを詰めた状態で16ステップごとに区切ります。チェックを外すと、スペースや記号も1文字分の休符としてそのまま含めて解釈します。

## その他の操作

- **テンポ**: 60〜200 BPMの範囲でスライダーから調整できます。
- **音量**: 0〜100%の範囲でスライダーから調整できます。
- パターンは16ステップ(1小節)ごとに区切って表示され、文章が16文字を超える場合は複数小節に分かれて連続再生されます。
- 再生中は現在鳴っているステップがグリッド上でハイライトされます。

## 動作環境

Web Audio APIに対応したモダンブラウザ(Chrome、Safari、Firefox、Edgeなど)で動作します。サーバーやインストールは不要で、ファイルを直接開くだけで使用できます。
