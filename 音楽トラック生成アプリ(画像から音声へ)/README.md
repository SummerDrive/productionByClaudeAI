# SCANLINE — 画像走査シンセサイザー（Phase 1）

画像の画素を機械的に音へ変換する、ブラウザ完結型の音楽生成ツールです。
「画像の雰囲気を曲にする」のではなく、**横方向＝時間、縦方向＝音程・楽器**という決められたルールに従って画素を音へ置き換える、走査（スキャン）型のシーケンサーです。

デモ: 単一のHTMLファイルとして動作し、サーバー不要でブラウザで開くだけで使用できます。

## 特徴

- **画像をそのまま楽譜として扱う**：画像を任意の解像度に縮小し、左から右へ列（時間）を走査。各列内の画素の縦位置がそのまま音程に対応し、画素の暗さが音の強さになります
- **4トラックへの自動振り分け**：画像の縦方向を4つの帯に分割し、それぞれ異なる楽器として鳴らします

  | 帯（縦方向の位置） | 楽器 | 挙動 |
  |---|---|---|
  | 上から25% | シンセ：白玉 | コード区間ごとに1回発音し、持続 |
  | 次の25% | シンセ：アルペジオ | 1ステップごとに発音 |
  | 次の25% | ベース | コードのルート音（単音）を発音 |
  | 下から25% | ドラム | ハイハット／スネア／キックの3レーン |

- **コード進行機能**：`Dm7, G7, Cmaj7, Am7` のようにコードをカンマ区切りで入力すると、走査時間全体に均等配置してパッド伴奏として鳴らします
  - 分数コード対応：`F/G`, `Caug/D` のようなスラッシュ表記
  - テンション対応：`Dm7(9)`, `G7(b9,13)` のように括弧で追加指定
- **ハーモナイズ**：メロディ／ベースの音程をその瞬間のコード構成音へスナップし、協和した響きに調整可能
- **走査線オーバーレイ**：再生中、今どの列が音になっているかを画像上のスキャンラインでリアルタイム表示

## 使い方

1. `scanline_phase1.html` をブラウザで開く
2. 画像をドラッグ&ドロップ、またはクリックして選択（サンプル画像でも試せます）
3. テンポ・解像度・音階・コード進行などのパラメータを調整
4. ▶ 再生ボタンで音を確認

## 技術構成

- 単一HTMLファイル（外部ビルド不要）
- 音声合成: [Tone.js](https://tonejs.github.io/)
- 画像解析: Canvas API（`getImageData`）

## 現在の制限 / 今後の予定

- 音声のダウンロード（wav / mp3 書き出し）は未実装
