MaskingTool 登録データの手動削除方法
====================================

はい、アプリを直接改造しなくても、保存されているJSONファイルを
テキストエディタで書き換えるだけで登録内容を削除できます。


1. ファイルの場所
------------------
以下のパスに保存されています。

  %APPDATA%\MaskingTool\mapping.json

エクスプローラーのアドレス欄に「%APPDATA%\MaskingTool」と入力して
Enterを押すと、そのフォルダが開きます。


2. 編集前に必ずアプリを閉じる
------------------------------
MaskingTool.exe を起動したままファイルを編集すると、
アプリ終了時（または次回の「変換」実行時）に古い内容で
上書きされてしまうことがあります。
必ずアプリを閉じた状態で編集してください。


3. ファイルの中身（例）
------------------------
メモ帳やVSCodeなどのテキストエディタで開くと、以下のような形式に
なっています。

[
  {
    "original": "proj-1234-abcd",
    "masked": "xxxxxxxxxxxxxx1",
    "assignedChar": "x",
    "number": 1,
    "length": 14
  },
  {
    "original": "client_田中太郎",
    "masked": "yyyyyyyyyyyyy1",
    "assignedChar": "y",
    "number": 1,
    "length": 13
  }
]

1件が { } で囲まれた1つのブロックになっています。


4. 特定の1件だけを削除する方法
--------------------------------
削除したいエントリの { から } までを、前後のカンマ関係に注意して
まるごと削除してください。

【削除前】
[
  { "original": "proj-1234-abcd", "masked": "xxxxxxxxxxxxxx1", ... },
  { "original": "client_田中太郎", "masked": "yyyyyyyyyyyyy1", ... },
  { "original": "id-9981", "masked": "zzzzzzz1", ... }
]

真ん中の "client_田中太郎" の行を削除する場合、
その行を消して、前後のカンマの数が正しくなるように調整します。

【削除後】
[
  { "original": "proj-1234-abcd", "masked": "xxxxxxxxxxxxxx1", ... },
  { "original": "id-9981", "masked": "zzzzzzz1", ... }
]

※ ポイント：一番最後の要素の後ろにカンマを残さないこと。
   （JSONでは最後の要素の後にカンマがあるとエラーになります）


5. 全件をまとめて削除する方法
--------------------------------
ファイルの中身をすべて選択して削除し、以下の2文字だけを
残して保存すれば、登録内容は空っぽになります。

  []


6. 保存時の注意
------------------
・ファイルの文字コードは UTF-8 で保存してください
  （メモ帳の場合、「名前を付けて保存」→ 文字コードで「UTF-8」を選択）
・保存後、括弧 { } [ ] の数が合っているか、カンマの位置が
  おかしくないか、ざっと見直してから保存すると安全です
・壊れたJSON（構文エラー）のまま保存してしまうと、次回アプリ起動時に
  読み込みエラーになる可能性があります。心配な場合は、編集前に
  mapping.json をコピーしてバックアップを取ってから作業してください


7. 削除後に新しく登録するとどうなるか
----------------------------------------
削除後にアプリで新規登録すると、その時点で残っている件数を基準に
x → y → z の割り当てと連番が決まります（登録済み件数からの連番のため）。
削除によって過去に発行した変換後文字列（例: yyyyyyyyyyyyy1）が
将来また別の文字列に再割り当てされる可能性はありますが、
これは動作上の不具合ではなく仕様です。もし過去にコピー済みの
変換後文字列と重複させたくない場合は、削除ではなく該当行の
"original" の値だけを別の値に書き換える、という運用も可能です。
