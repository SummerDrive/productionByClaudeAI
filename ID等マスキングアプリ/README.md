# MaskingTool

クライアント固有の文字列（ID・プロジェクト名など）を、コマンドやエラーメッセージの中から
`xxxxxx1` のような匿名化文字列に置換するための、Windowsタスクバー常駐型のローカルツールです。

## 重要：このファイル一式について

このコード一式は **このチャットの実行環境（ネットワーク遮断・.NET SDK未インストールのLinuxサンドボックス）では
コンパイルできませんでした。** apt / dotnet SDKのインストールを試みましたが、外部ネットワークへの
アクセスが許可されておらずダウンロードに失敗しました（403 Forbidden）。

そのため、**ソースコード一式・アイコン（app.ico）・ビルド用スクリプトを完成させた状態で** お渡しします。
お手元のWindows PCで下記の手順を実行するだけで、`MaskingTool.exe` が生成されます。

## ビルド手順（お手元のWindows PCで）

1. [.NET 8 SDK](https://dotnet.microsoft.com/download) をインストール（未導入の場合）
2. この `MaskingTool` フォルダをそのままコピー
3. フォルダ内の `build.bat` をダブルクリック（またはコマンドプロンプトで `dotnet publish -c Release -r win-x64 --self-contained true`）
4. 生成された実行ファイルを確認:
   ```
   bin\Release\net8.0-windows\win-x64\publish\MaskingTool.exe
   ```
5. `MaskingTool.exe` を右クリック →「タスクバーにピン留めする」でタスクバーに常駐できます。
   （自己完結ビルドのため .NETランタイムのインストールは不要です。ファイルサイズは60〜80MB程度になります）

## 使い方

### 登録タブ
1. クライアントID・プロジェクト名などを1行に1件ずつ入力
2. 「変換」ボタンを押すと、匿名化文字列が自動採番され下の一覧に追加される
3. 登録内容は `%APPDATA%\MaskingTool\mapping.json` に自動保存され、次回起動時も引き継がれる

### 編集タブ
1. コマンドやエラーメッセージを貼り付け
2. 「編集」ボタンを押すと、登録済み文字列がすべて匿名化文字列に置換されて下に表示される
3. 「コピー」ボタンでクリップボードにコピーできる

## 匿名化文字列のルール

登録順に `x → y → z` の文字を3件ごとに繰り返し使用し、元の文字列と同じ文字数だけ並べて
末尾に連番を付与します。

| 登録順 | 元の文字列（文字数） | 変換後 |
|---|---|---|
| 1件目 | `abc123`（6文字） | `xxxxxx1` |
| 2件目 | `proj-9`（6文字） | `yyyyyy1` |
| 3件目 | `田中太郎`（4文字） | `zzzz1` |
| 4件目 | `clientX`（7文字） | `xxxxxxx2` |

## ファイル構成

```
MaskingTool/
 ├─ MaskingTool.csproj   … プロジェクト定義（自己完結・単一exe設定込み）
 ├─ Program.cs           … エントリポイント
 ├─ MainForm.cs          … 画面（登録タブ／編集タブ）
 ├─ Masker.cs            … 文字列置換ロジック
 ├─ MappingStore.cs      … 登録データの保存・読込・採番ロジック
 ├─ MappingEntry.cs      … 1件分のマッピングデータ
 ├─ app.ico              … アプリアイコン（盾＋「変」／背景ヴェイパーウェイブ配色）
 ├─ Assets/icon_preview.png … アイコンの拡大プレビュー画像
 ├─ build.bat            … ビルド用バッチファイル
 └─ README.md            … このファイル
```

## 注意事項

- 置換は完全一致文字列の置換です（正規表現ではありません）。長い文字列から順に処理するため、
  短い登録文字列が長い文字列の一部を誤って壊すことは基本的にありません。
- 大文字・小文字は区別します。
- データはすべてローカル（`%APPDATA%\MaskingTool\`）に保存され、外部には送信されません。
